## Synopsis

The vet command builds the local module and validates the resulting Kubernetes objects.

```
timoni mod vet [MODULE PATH] [flags]
```

## Examples

```sh
  # validate module using default values
  timoni mod vet

  # validate module using debug values
  timoni mod vet ./path/to/module --debug

```

## Options

```
      --debug             Use debug_values.cue if found in the module root instead of the default values.
  -h, --help              help for vet
      --name string       Name of the instance used to build the module (default "default")
  -p, --package package   The name of the module's package used for building the templates. (default main)
  -f, --values strings    The local path to values files (cue, yaml or json format).
```
