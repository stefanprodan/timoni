## Synopsis

The tag command allows adding tags to an existing artifact.

```
timoni artifact tag ARTIFACT_URL [flags]
```

## Examples

```sh
  # Tag an existing artifact with a new tags
  echo $DOCKER_PAT | docker login --username timoni --password-stdin
  timoni artifact tag oci://docker.io/org/app:1.0.0 -t 1.0 -t latest

```

## Options

```
      --creds creds       The credentials for the container registry in the format '<username>[:<password>]'.
  -h, --help              help for tag
  -t, --tag stringArray   Tag of the artifact.
```
