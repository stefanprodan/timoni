---
title: "timoni build"
description: "Build an instance from a module and print the resulting Kubernetes resources"
mode: "wide"
---

```
timoni build INSTANCE_NAME MODULE_URL [flags]
```

## Examples

```sh
  # Build an instance from a local module
  timoni build app ./path/to/module --output yaml

  # Build an instance with custom values by merging them in the specified order
  timoni build app ./path/to/module \
  --values ./values-1.cue \
  --values ./values-2.cue

```

## Options

```
      --creds creds       The credentials for the container registry in the format '<username>[:<password>]'.
  -d, --digest digest     The digest of the module e.g. sha256:3f29e1b2b05f8371595dc761fed8e8b37544b38d56dfce81a551b46c82f2f56b.
  -h, --help              help for build
      --mask-secrets      Hide the values of Kubernetes Secrets in the printed objects.
  -o, --output string     The format in which the Kubernetes objects should be printed, can be 'yaml' or 'json'. (default "yaml")
  -p, --package package   The name of the module's package used for building the templates. (default main)
  -f, --values strings    The local path to values files (cue, yaml or json format).
  -v, --version version   The version of the module e.g. '1.0.0' or '1.0.0-rc.1'.
```
