## Synopsis

The bundle build command builds and prints the resulting Kubernetes resources for all instances defined in a Bundle.


```
timoni bundle build [flags]
```

## Examples

```sh
  # Build all instances from a bundle and print the manifests to stdout
  timoni bundle build -f bundle.cue

  # Pass secret values from stdin
  cat ./bundle_secrets.cue | timoni bundle build -f ./bundle.cue -f -

  # Write the manifests as a directory tree, one directory per instance
  # and one file per resource, named like 'kustomize build -o <dir>'
  timoni bundle build -f bundle.cue --output-dir ./manifests

```

## Options

```
      --concurrency int     The number of instances to build concurrently, defaults to the number of CPU cores capped at 8.
      --creds creds         The credentials for the container registry in the format '<username>[:<password>]'.
  -f, --file strings        The local path to bundle.cue files.
  -h, --help                help for build
      --mask-secrets        Hide the values of Kubernetes Secrets in the printed objects, ignored with --output-dir.
      --output-dir string   The path to a directory where the manifests are written as a tree, one directory per instance and one file per resource.
  -p, --package package     The name of the module's package used for building the templates. (default main)
```
