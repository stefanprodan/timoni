---
title: "timoni mod vendor k8s"
description: "Vendor Kubernetes API CUE schemas"
mode: "wide"
---

```
timoni mod vendor k8s [MODULE PATH] [flags]
```

## Examples

```sh
  # Vendor CUE schemas generated from the latest Kubernetes GA APIs
  timoni mod vendor k8s

  # Vendor CUE schemas generated from a specific version of Kubernetes GA APIs
  timoni mod vendor k8s -v 1.28

```

## Options

```
  -h, --help             help for k8s
  -v, --version string   The Kubernetes minor version e.g. 1.28. (default "latest")
```
